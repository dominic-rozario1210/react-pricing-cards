# React Pricing Cards UI

A responsive pricing cards UI built with **React** using reusable components and dynamic rendering with `.map()`.

## 🚀 Features

- Responsive pricing card layout
- Reusable `PricingCard` component
- Dynamic rendering using `.map()`
- Pricing plan data stored separately
- Modern gradient background
- Hover effect on cards
- Responsive design for desktop, tablet, and mobile
- Open Sans font

## 🛠️ Technologies Used

- React
- JavaScript
- CSS
- Vite
